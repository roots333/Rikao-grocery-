# Rikao - Grocery Delivery & Services

Nagaur-focused grocery delivery website.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and the `assets` folder.
3. Go to Settings → Pages.
4. Select the `main` branch and `/root` folder.
5. Save; GitHub will publish the site.

The site is designed to work without external libraries or image URLs.
